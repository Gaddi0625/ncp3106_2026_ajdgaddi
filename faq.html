General Questions

Computer Engineering integrates electrical engineering and computer science, focusing on the hardware-software interface. Computer Science focuses primarily on software, algorithms, and theoretical computing. Computer Engineers design both hardware (circuits, processors, embedded systems) and the low-level software (firmware, drivers, RTOS) that runs on it.

No. Computer Engineering covers both hardware and software. The balance and specific topics vary by institution and curriculum.

Yes. Computer Engineering programs commonly include programming for hardware, embedded systems, and software applications. The languages taught vary by institution and curriculum.

  • C / C++ — Embedded systems, firmware, real-time systems
  • Python — Scripting, data analysis, ML/AI, testing
  • Verilog / VHDL — Digital logic design, FPGA development
  • Assembly — Microcontroller programming, optimization
  • Java / JavaScript — Applications, web interfaces for embedded systems
  • MATLAB — Signal processing, control systems

UE Computer Engineering Program

Computer Engineering may be applied in areas including multimedia, aerospace and avionics, automotive systems, consumer electronics, medical devices, communications, entertainment, virtual reality hardware, and human-interface devices.

Admissions & Careers

UE lists these career paths: Project Engineer/Manager, Network System Administrator/Manager, Data Communications Engineer, Systems Engineer/Developer/Manager, Systems Analyst/Designer, Technical Support Engineer/Manager, Test Engineer, Technopreneur, Software Engineer, Educator and Researcher. Additional industry roles include Embedded Systems Engineer, IoT Engineer, Hardware Engineer, Cybersecurity Engineer, AI/ML Engineer, Cloud Engineer, DevOps Engineer, Robotics Engineer, and R&D Engineer.

  • Strong foundation in mathematics (calculus, discrete math, linear algebra)
  • Physics fundamentals (electricity, magnetism, mechanics)
  • Basic programming experience (any language)
  • Logical thinking and problem-solving skills
  • Interest in how hardware and software interact
  • Willingness to learn circuit analysis and digital logic
