Foundational Skills

These core competencies support work across all Computer Engineering domains.

Mathematics

Discrete math, linear algebra, calculus, probability, and statistics for algorithm analysis, signal processing, and system modeling.

Physics & Electronics

Circuit theory, digital logic, semiconductor physics, and electromagnetics for hardware design and embedded systems.

Programming Fundamentals

Data structures, algorithms, memory management, and software engineering principles in C, C++, and Python.

Systems Thinking

Understanding how hardware and software interact at the system level; co-design, optimization, and trade-off analysis.

Problem Solving

Analytical reasoning, debugging, root cause analysis, and designing solutions under constraints.

Communication

Technical writing, cross-functional collaboration, and presenting engineering decisions to diverse audiences.

Skill Development Pathways

Typical progression for building expertise in Computer Engineering skill areas.

Embedded & Hardware

  • C/C++, digital logic, microcontrollers
  • RTOS, bare-metal programming, peripherals
  • PCB design, Verilog/VHDL, FPGA
  • ASIC flow, timing analysis, low-power design

Software & Systems

  • Data structures, algorithms, Git, Linux
  • Systems programming, networking, databases
  • Distributed systems, cloud platforms, containers
  • DevOps, observability, platform engineering

Security & Emerging

  • Cryptography basics, secure coding, threat modeling
  • Network security, embedded security, forensics
  • ML fundamentals, PyTorch/TensorFlow, edge AI
  • Robotics (ROS), quantum computing basics

These skill categories and pathways are general guidance for Computer Engineering students and professionals. They do not represent official UE Manila course requirements or a verified curriculum. Consult the UE Manila College of Engineering for current program details.
